# NUWAI Docs

Living documentation for the NUWAI platform build.

## Layout

- `roadmap.md` — phased build plan from analysis to launch
- `decisions/` — architecture decision records (ADRs); newest at the top of the index
- `changelog.md` — running log of what shipped, by phase
- `pages/` — per-route spec (purpose, content, components, auth gates)
- `glossary.md` — shared brand + product vocabulary

Update `changelog.md` at the end of every working session. Add an ADR whenever a non-trivial decision is made — the goal is that a new contributor (or future-Jon) can read `docs/` and understand *why* the codebase looks the way it does.
